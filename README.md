# 在线课堂 - 视频播放器

## 怎么用

### 1. 把视频放进去

把你的录课视频文件放到 `videos` 文件夹里。

### 2. 修改视频列表

用记事本打开 `index.html`，找到 `COURSE_VIDEOS` 这一段，改成你自己的课程：

```javascript
const COURSE_VIDEOS = [
    {
        id: '1',
        title: '第一课：函数的定义',
        src: 'videos/lesson1.mp4',   // 视频文件路径
        duration: '45:30',
        tags: ['数学', '必修一'],
        date: '2026-07-20',
    },
    {
        id: '2',
        title: '第二课：函数的单调性',
        src: 'videos/lesson2.mp4',
        duration: '42:15',
        tags: ['数学', '必修一'],
        date: '2026-07-22',
    },
];
```

### 3. 先在本地试试

双击 `index.html` 就能在浏览器里看到效果。

## 怎么分享给学生

有几个方案，按推荐顺序排列：

### 方案一：部署到网上（推荐）

把整个 `course-videos` 文件夹上传到免费托管平台，生成一个链接发给学生。

**推荐平台：**
- **GitHub Pages** — 免费，稳定
- **Gitee Pages（码云）** — 免费，国内速度快

然后视频文件可以：
- 也放在项目里一起部署（视频需要压缩到合适大小）
- 或者上传到**七牛云**（免费 10GB，国内速度极快），把链接填到 `src` 里

### 方案二：视频传网盘 + 链接填进去

1. 把视频上传到支持在线播放的网盘
2. 获取视频的直链地址
3. 把链接填到 `index.html` 的 `src` 里
4. 只部署 `index.html` 到 GitHub Pages

### 方案三：临时分享（电脑需要开着）

如果你的电脑一直开着，可以运行一个简单的服务，学生通过链接直接访问你的电脑。

## 视频压缩建议

录课视频通常很大，建议先压缩一下：

- **分辨率**：1280×720（720P）就够了，黑板字能看清
- **码率**：1000-1500 kbps 即可
- **工具**：HandBrake（免费）、格式工厂

一节 45 分钟的课，压缩后大概 300-500MB。
